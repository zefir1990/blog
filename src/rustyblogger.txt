Title: RustyBlogger — блог на Rust с собственной базой данных
Slug: rustyblogger

RustyBlogger — это движок для блога, который я написал на Rust.
Он хранит посты в embedded-базе redb, рендерит полноценные HTML-страницы и отдаёт их через axum.
Внешняя база данных, ORM и отдельный frontend не нужны: всё работает в одном бинарнике.

<h2>Зачем ещё один блог</h2>
Мне хотелось получить сайт, который быстро запускается, не требует инфраструктуры и при этом поддерживает несколько языков. RustyBlogger читает посты из redb, умеет переключать язык, показывает категории и отдаёт OpenGraph-превью для социальных сетей.

<h2>Как это устроено</h2>
Посты лежат в таблицах redb. Для каждого языка хранится отдельный вариант текста, а slug связывает переводы между собой. Если перевода нет, сайт показывает язык по умолчанию и предупреждает об этом. Язык выбирается по параметру lang, cookie или заголовку Accept-Language.

Маршруты собраны в одном axum-роутере. Помимо HTML-страниц есть JSON API и отдельный CRUD API для редактора. Запись постов защищена ключом rusty-blogger-post-editor-key, который хранится в настройках базы.

<h2>Публикация</h2>
Исходники постов лежат в отдельном репозитории в текстовом формате. Компилятор переводит заметку на девять языков, собирает HTML и отправляет варианты через API. Обновление существующего поста сохраняет дату публикации.

<pre><code>
cargo build --release
target/release/rustyblogger serve \
  --database blog.redb \
  --media-directory media \
  --bind-address 127.0.0.1:8080
</code></pre>
